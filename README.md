# Sherpalaxy GTA5 Teleport Mod

Click a pin on https://sherpalaxy.gg/gta/5 to teleport in GTA V (Legacy / Enhanced).

## Download
Get the latest zip from [Releases](https://github.com/Sherpalaxy/gta5-teleport-mod/releases/latest).

## Antivirus warnings
The mod injects a DLL into the game, so some antivirus engines flag it by behavior. This is a false positive. Each release zip includes VIRUSTOTAL.txt with the exe's SHA-256 and scan link. False-positive reports have been sent to Microsoft and other vendors; until they are reviewed, Windows Defender may warn or block the file.
